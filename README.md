#### 1. Explanation of at least TWO steps of Machine Learning
  1. **Step 2: Choosing the Model**
     Developers choose a model based on the type of problem they are trying to solve. This often involves a process        of trial and error. Within the insurance industry a classification model is often used to assist in the               classification of claim severity so those that are ranked high can receive priority.
     
  2. **Step 3: Training the Model**
     Models are trained using historical data. In the aforementioned example of claim severity, historical claims that
     already have a classification are used to establish patterns the model can use to classify the severity of new
     claims. During the training phase the model adjusts to improve accuracy as it receives more information.

#### What application of Machine Learning did you discover while researching?
The application of Machine Learning that I researched is Litigation Prediction in the insurance industry. This model can determine the probability that a claim will result in a lawsuit. 

  **a. How does Machine Learning improve or replace existing solutions?**

    In the past, insurers relied on their adjusters' experience, simple business rules, and basic reporting to make       determinations on likelihood of a claim becoming litigated. With the introduction of machine learning, a model        can learn the relationships between claim type, injury severity, property damage amount, prior claim history,         court jurisdiction, medical treatment, previous litigation outcomes, etc. The model learns what combination of        these variables tends to result in lawsuits sooner in the claims process and with greater accuracy then               traditional methods. This also allows for better financial forecasting. 

  **b. Is the application in development or actively being used by companies/institutions?**
  
    This application is actively being used by companies/institutions but continues to be improved with better data.      The addition of Agentic AI will also enable the models to make recommendation for next steps based on information     received.

#### Describe at least ONE ethical concern using Machine Learning for this application?
This application has an ethical concern common to many use cases of Machine Learning. The data used to train the models comes from past claims data. If there were biases in the claim-handling practices that produces the data used to train the model, those biases would be carried over into the predictions made by the model. This is important because actions may be taken that are unnecessary and possibly costly if biased data was used to make a prediction that a claim has a high probability of litigation when in reality it does not.
